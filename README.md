# Portfolio — Nguyễn Duy Trường

Static site: one `index.html` plus image folders. No build step.

- `index.html` — the whole site (HTML, CSS, JS in one file)
- `covers/` — project covers and portrait
- `cs/` — case study images (rebuilt with sample data)
- `full/` — full screen sheets for project pages
- `prv/` — long previews for client work

Run locally: open `index.html`, or run `python3 -m http.server 8000` in this folder and visit http://localhost:8000.

Hosting: GitHub Pages, branch `main`, folder `/ (root)`.
